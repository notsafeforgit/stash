# Optional integrations

Reusable Python API clients have moved to
[stash-integrations](https://github.com/notsafeforgit/stash-integrations), with
independent releases and tests. They can run in an existing operations container
or on a host; ordinary Stash use requires none of them.

See [optional integrations](../docs/optional-integrations.md) for the API boundary
and [the client compatibility guide](../docs/integration-client-tests.md) for
maintaining the server/client contract.
