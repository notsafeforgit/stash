# Final v2.5 compatible release

The independent native archive development line starts after source commit
0a603d07e9ec3dd9863a7340858a635525bb2c11, tagged v2.5-compatible-final.
The frozen image digests are recorded in
[the release manifest](v2.5-compatible-final.json). Preservation publishes those
existing images without rebuilding them. Workflow receipts verify the image
digests and embedded Stash revision; publication is complete only when those
workflows succeed.

| Runtime | Compatible release tag |
| --- | --- |
| Stash image | ghcr.io/notsafeforgit/stash:v2.5-compatible-final |
| Debian hardware acceleration wrapper | ghcr.io/notsafeforgit/stash-s6:hwaccel-v2.5-compatible-final |
| Alpine wrapper | ghcr.io/notsafeforgit/stash-s6:alpine-v2.5-compatible-final |
| Alpine hardware acceleration wrapper | ghcr.io/notsafeforgit/stash-s6:hwaccel-alpine-v2.5-compatible-final |

Each has a dated 20260930 alias. These tags must never be moved to a different
digest. Companion content tags protect index children from untagged-image
cleanup. Using the manifest's digest provides an additional immutable pin.

To stay on the compatible release, pin the appropriate image above and disable
automatic upgrades to the native preview line. Keep a backup of the database,
configuration, original artwork, and any externally managed catalog data. This
release uses primary schema 86 and fork schema 9 and still includes both UIs.

Switching to upstream requires an upstream version that supports the database's
primary schema, plus testing a copy of the database and config. Upstream does
not understand this fork's richer sidecar data or v3-only plugin features; retain
the original backup. Do this before migrating to the independent native schema.
A database already promoted by a future native release cannot simply be opened
by this image or an upstream binary.

Development continues on v3-rewrite. New Stash images from that branch use
native-preview and native-preview-<commit> tags so development cannot silently
replace the compatible v3-rewrite image. A native wrapper must explicitly select
its Stash source digest and publish to its own preview tags. The develop branch
is merged only after migration and deployment verification and success review.

This is a frozen fallback, not a promise of indefinite security maintenance.
Users remaining on upstream should follow upstream updates once their copy has
been verified there. StashDB/stash-box compatibility remains a requirement of
the independent native release.
